# Projeto Solaris — versão profissional

Site demonstrativo acadêmico com visual premium e responsivo.

Arquivos:
- index.html
- style.css
- script.js

Recursos:
- Landing page
- Simulador demonstrativo de economia
- Jornada de uso
- Área de planejamento financeiro
- Chatbot Solaris IA demonstrativo
- Layout responsivo para celular e computador

GitHub Pages:
1. Coloque `index.html`, `style.css` e `script.js` na raiz do repositório.
2. Configurações → Pages.
3. Implantar a partir de uma ramificação.
4. Branch: `main` (ou a branch principal do seu repositório).
5. Pasta: `/ (root)`.
6. Salve.
